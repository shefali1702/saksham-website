 🌟 SAKSHAM — Every Child, Every Right

 SAKSHAM is a web-based gamified platform that teaches children aged 8 to 16 about their legal rights, right to education, protection from      child labor, protection from abuse (POCSO) and protection from child marriage through interactive stories, choices and quizzes set in an       illustrated town[cite: 1]. Each right is a building the child unlocks by playing through a scenario, seeing the real world consequence of a    wrong choice, learning the actual law and passing a short quiz[cite: 1]. The app requires no login, runs entirely in the browser, stores       progress only on the device and keeps a calm, always-visible Help Centre with real emergency and legal-aid contacts[cite: 1]. It is built to   be free to host, easy to extend (a new right is just one new content file) and immediately usable by schools and NGOs through a single  link[cite: 1].

Unlike posters, lectures, or generic edtech apps, SAKSHAM teaches legal rights through situations children actually recognise, a friend being pulled out of school, a wage denied at a dhaba and lets them make a choice and see the consequence before the actual law is explained[cite: 1]. It needs no install, no login and no server, so it runs on any shared or low-end phone a school already has, with a help button (Childline/112/NALSA) on every single screen[cite: 1].

---

## ✨ Features

- 🏛️ **Illustrated Town Map:** Walk through town buildings (School, Dhaba, Safe House, Panchayat) to access rights scenarios[cite: 1].
- 🎮 **Scenario-Based Learning:** Interactive stories and decision points where choices show real-world consequences[cite: 1].
- 📜 **Legal Awareness:** Clear, accessible explanations of legal rights, RTE, POCSO, child labor laws, and child marriage protection[cite: 1].
- 📝 **Knowledge Quizzes:** Short quizzes to evaluate learning and unlock progress[cite: 1].
- 🚨 **Always-Visible Help Centre:** Quick access to emergency helplines (112, Childline, NALSA legal aid) on every screen[cite: 1].
- 🔒 **Zero Data Collection:** No login required, no server tracking, and progress stored locally on device[cite: 1].

## 🚀 Quick Start

### Running Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/shefali1702/saksham-website.git](https://github.com/shefali1702/saksham-website.git)

```

2. Navigate into the directory:
```bash
cd saksham-website

```


3. Open `index.html` in any web browser.
